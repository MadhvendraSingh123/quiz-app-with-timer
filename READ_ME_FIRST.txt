This Web-based Application requires an API KEY to function properly.
This program in particular is designed to use a 'Groq' API key.

API KEY SETUP (REQUIRED)
------------------------------------------------------------------------
This application requires an active Groq API Key to generate questions. 
Please follow these steps to configure your key:

1. Obtain a free API key from the Groq Developer Console:
   https://console.groq.com/

2. Open the file `fetch_questions.php` in any code or text editor.

3. Locate Line 17:
   $apiKey = "API_KEY_HERE";

4. Replace `API_KEY_HERE` with your actual Groq API key:
   $apiKey = "gsk_1234567890abcdef...";

5. Save and close the file.
